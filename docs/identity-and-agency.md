# Identity and agency

HEKATE has one durable principal and one configured user principal. Identity versions and their boundaries are persisted. A relationship connects both principals and carries unresolved conflicts and shared commitments.

The Thought Cycle is cognitive provenance: draft, self-review, and committed judgment. It does not grant execution authority. The action plane records an intent, evaluates policy, requests approval when required, starts an operation, captures a receipt, verifies the result, and records artifact provenance. Explicit user memory commands can promote a candidate; inferred candidates remain inactive until promoted.
